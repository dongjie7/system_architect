## 一、进程调度计算

### 1.1 周转时间、等待时间计算

**公式：**
```
周转时间 = 完成时间 - 到达时间
等待时间 = 周转时间 - 服务时间
响应时间 = 首次上CPU时间 - 到达时间
带权周转时间 = 周转时间 / 服务时间

平均周转时间 = Σ周转时间 / n
平均等待时间 = Σ等待时间 / n
```

### 1.2 典型题目

**题目**：5个进程到达时间和服务时间如下，计算各调度算法的平均等待时间。

| 进程 | 到达时间 | 服务时间 | 优先级 |
|------|----------|----------|--------|
| P1   | 0        | 10       | 3      |
| P2   | 1        | 1        | 1      |
| P3   | 2        | 2        | 4      |
| P4   | 3        | 1        | 2      |
| P5   | 4        | 5        | 5      |

**FCFS解答**：
```
执行顺序: P1 → P2 → P3 → P4 → P5

P1: 完成=10, 周转=10-0=10, 等待=10-10=0
P2: 完成=11, 周转=11-1=10, 等待=10-1=9
P3: 完成=13, 周转=13-2=11, 等待=11-2=9
P4: 完成=14, 周转=14-3=11, 等待=11-1=10
P5: 完成=19, 周转=19-4=15, 等待=15-5=10

平均等待时间 = (0+9+9+10+10)/5 = 7.6
平均周转时间 = (10+10+11+11+15)/5 = 11.4
```

**SJF（非抢占）解答**：
```
P1先执行（0-10）
P1完成后，P2,P3,P4,P5都已到达
按服务时间排序: P2(1), P4(1), P3(2), P5(5)
执行顺序: P1 → P2 → P4 → P3 → P5

P1: 完成=10, 周转=10, 等待=0
P2: 完成=11, 周转=10, 等待=9
P4: 完成=12, 周转=9, 等待=8
P3: 完成=14, 周转=12, 等待=10
P5: 完成=19, 周转=15, 等待=10

平均等待时间 = (0+9+8+10+10)/5 = 7.4
```

**SRTF（抢占式SJF）解答**：
```
时间0: P1到达，执行P1（剩余10）
时间1: P2到达，P1剩9，P2需1，切换执行P2
时间2: P2完成，P1剩9，P3到达需2，执行P3
时间3: P3剩1，P4到达需1，执行P4
时间4: P4完成，P3剩1，P5到达需5，执行P3
时间5: P3完成，P1剩9，P5需5，执行P5
时间10: P5完成，执行P1
时间19: P1完成

执行顺序: P1(0-1) → P2(1-2) → P3(2-4) → P4(4-5) → P5(5-10) → P1(10-19)

P1: 完成=19, 周转=19, 等待=9
P2: 完成=2, 周转=1, 等待=0
P3: 完成=5, 周转=3, 等待=1
P4: 完成=5, 周转=2, 等待=1
P5: 完成=10, 周转=6, 等待=1

平均等待时间 = (9+0+1+1+1)/5 = 2.4
```

**RR（时间片=1）解答**：
```
就绪队列: [P1, P2, P3, P4, P5]
时间片=1

时间0-1: P1执行1单位（剩9）→ P2到达，入队
时间1-2: P2执行1单位（完成）→ P3到达，入队
时间2-3: P3执行1单位（剩1）→ P4到达，入队
时间3-4: P4执行1单位（完成）→ P5到达，入队
时间4-5: P5执行1单位（剩4）
时间5-6: P1执行1单位（剩8）
时间6-7: P3执行1单位（完成）
时间7-12: P5执行5单位（完成）
时间12-19: P1执行7单位（完成）

P1: 完成=19, 周转=19, 等待=9
P2: 完成=2, 周转=1, 等待=0
P3: 完成=7, 周转=5, 等待=3
P4: 完成=4, 周转=1, 等待=0
P5: 完成=12, 周转=8, 等待=3

平均等待时间 = (9+0+3+0+3)/5 = 3.0
```

## 二、银行家算法计算

### 2.1 计算步骤

```
1. 计算Available = Total - ΣAllocation
2. 计算Need = Max - Allocation
3. 安全性检查：
   - 初始化Work = Available
   - 找Need[i] ≤ Work且Finish[i]=false的进程
   - 找到则Work += Allocation[i]，Finish[i]=true
   - 重复直到所有进程完成或找不到
4. 资源请求处理：
   - 检查Request ≤ Need
   - 检查Request ≤ Available
   - 试探分配后执行安全性检查
```

### 2.2 典型题目

**题目**：系统有A(17)、B(5)、C(20)三类资源，T0时刻状态如下：

| 进程 | Max(A,B,C) | Allocation(A,B,C) |
|------|------------|-------------------|
| P1   | 5,5,9      | 2,1,2             |
| P2   | 5,3,6      | 4,0,2             |
| P3   | 4,0,11     | 3,0,2             |
| P4   | 4,2,5      | 2,0,1             |
| P5   | 4,3,6      | 3,1,2             |

**解答**：

```
1. 计算Available
   A: 17-(2+4+3+2+3) = 3
   B: 5-(1+0+0+0+1) = 3
   C: 20-(2+2+2+1+2) = 11
   Available = (3, 3, 11)

2. 计算Need
   P1: (5-2, 5-1, 9-2) = (3, 4, 7)
   P2: (5-4, 3-0, 6-2) = (1, 3, 4)
   P3: (4-3, 0-0, 11-2) = (1, 0, 9)
   P4: (4-2, 2-0, 5-1) = (2, 2, 4)
   P5: (4-3, 3-1, 6-2) = (1, 2, 4)

3. 安全性检查
   Work = (3, 3, 11)
   
   第1轮：
   - P1: Need(3,4,7) ≤ Work(3,3,11)? B:4>3 ✗
   - P2: Need(1,3,4) ≤ Work(3,3,11)? ✓ → Work=(3,3,11)+(4,0,2)=(7,3,13)
   - P3: Need(1,0,9) ≤ Work(7,3,13)? ✓ → Work=(7,3,13)+(3,0,2)=(10,3,15)
   - P4: Need(2,2,4) ≤ Work(10,3,15)? ✓ → Work=(10,3,15)+(2,0,1)=(12,3,16)
   - P5: Need(1,2,4) ≤ Work(12,3,16)? ✓ → Work=(12,3,16)+(3,1,2)=(15,4,18)
   
   第2轮：
   - P1: Need(3,4,7) ≤ Work(15,4,18)? ✓ → Work=(15,4,18)+(2,1,2)=(17,5,20)
   
   安全序列：<P2, P3, P4, P5, P1>
   结论：系统安全

4. P1请求(1,2,3)
   - Request(1,2,3) ≤ Need(3,4,7) ✓
   - Request(1,2,3) ≤ Available(3,3,11) ✓
   - 试探分配：
     Available = (3,3,11)-(1,2,3) = (2,1,8)
     Allocation[1] = (2,1,2)+(1,2,3) = (3,3,5)
     Need[1] = (3,4,7)-(1,2,3) = (2,2,4)
   
   - 安全性检查：
     Work = (2, 1, 8)
     P1: Need(2,2,4) ≤ Work(2,1,8)? B:2>1 ✗
     P2: Need(1,3,4) ≤ Work(2,1,8)? B:3>1 ✗
     P3: Need(1,0,9) ≤ Work(2,1,8)? C:9>8 ✗
     P4: Need(2,2,4) ≤ Work(2,1,8)? B:2>1 ✗
     P5: Need(1,2,4) ≤ Work(2,1,8)? B:2>1 ✗
     
     找不到可完成进程，不安全！
     结论：不能分配，P1必须等待
```

## 三、页面置换计算

### 3.1 缺页率计算

**公式：**
```
缺页率 = 缺页次数 / 总访问次数 × 100%
```

### 3.2 典型题目

**题目**：页面访问序列为 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5，分配4个页框，计算各算法缺页次数。

#### FIFO解答

```
访问序列: 1 2 3 4 1 2 5 1 2 3 4 5
页框1:    1 1 1 1 1 1 5 5 5 5 5 5
页框2:    - 2 2 2 2 2 2 2 2 2 2 2
页框3:    - - 3 3 3 3 3 3 3 3 3 3
页框4:    - - - 4 4 4 4 4 4 4 4 4

缺页: √ √ √ √       √
缺页次数: 5次（前4次是初始装入）
缺页率: 5/12 = 41.7%

注意：访问1,2时命中，只有5是新页，替换1
```

#### LRU解答

```
访问序列: 1 2 3 4 1 2 5 1 2 3 4 5
页框1:    1 1 1 1 1 1 5 5 5 5 5 5
页框2:    - 2 2 2 2 2 2 2 2 2 2 2
页框3:    - - 3 3 3 3 3 3 3 3 3 3
页框4:    - - - 4 4 4 4 4 4 4 4 4

最近使用顺序（每次访问后）：
访问1: [1]
访问2: [2,1]
访问3: [3,2,1]
访问4: [4,3,2,1]
访问1: [1,4,3,2] 命中
访问2: [2,1,4,3] 命中
访问5: [5,2,1,4] 替换3（最久未用）
访问1: [1,5,2,4] 命中
访问2: [2,1,5,4] 命中
访问3: [3,2,1,5] 替换4
访问4: [4,3,2,1] 替换5
访问5: [5,4,3,2] 替换1

缺页: √ √ √ √       √     √ √ √
缺页次数: 8次
缺页率: 8/12 = 66.7%
```

#### OPT解答

```
访问序列: 1 2 3 4 1 2 5 1 2 3 4 5
将来使用顺序分析：

访问1: 将来用到位置5,8 → 页框[1]
访问2: 将来用到位置6,9 → 页框[1,2]
访问3: 将来用到位置10 → 页框[1,2,3]
访问4: 将来用到位置11 → 页框[1,2,3,4]
访问1: 命中 → 页框[1,2,3,4]
访问2: 命中 → 页框[1,2,3,4]
访问5: 将来用到位置12 → 替换3（将来最远）→ 页框[1,2,5,4]
访问1: 命中 → 页框[1,2,5,4]
访问2: 命中 → 页框[1,2,5,4]
访问3: 将来不用 → 替换4（将来最远）→ 页框[1,2,5,3]
访问4: 将来不用 → 替换1（将来不用）→ 页框[4,2,5,3]
访问5: 命中 → 页框[4,2,5,3]

缺页: √ √ √ √       √     √ √
缺页次数: 7次（最优）
缺页率: 7/12 = 58.3%
```

## 四、磁盘调度计算

### 4.1 寻道距离计算

**公式：**
```
总寻道距离 = Σ|当前位置 - 目标位置|
```

### 4.2 典型题目

**题目**：磁盘有200个磁道（0-199），磁头当前位置在100，刚完成98的服务，正向磁道号增大方向移动。请求队列：55, 58, 39, 18, 90, 160, 150, 38, 184

#### FCFS

```
顺序: 55, 58, 39, 18, 90, 160, 150, 38, 184
距离: |100-55|+|55-58|+|58-39|+|39-18|+|18-90|+|90-160|+|160-150|+|150-38|+|38-184|
     = 45+3+19+21+72+70+10+112+146 = 498
```

#### SSTF

```
从100开始，每次选最近的：
100→90(10)→58(32)→55(3)→39(16)→38(1)→18(20)→150(132)→160(10)→184(24)
总距离 = 10+32+3+16+1+20+132+10+24 = 248
```

#### SCAN

```
向外扫到184，再向内扫到18：
100→150(50)→160(10)→184(24)→90(94)→58(32)→55(3)→39(16)→38(1)→18(20)
总距离 = 50+10+24+94+32+3+16+1+20 = 250
```

#### C-SCAN

```
向外扫到184，回到0，再扫到18：
100→150(50)→160(10)→184(24)→0(184)→18(18)→38(20)→39(1)→55(16)→58(3)→90(32)
总距离 = 50+10+24+184+18+20+1+16+3+32 = 358
```

#### LOOK

```
向外扫到最远请求184，反向扫到18：
100→150(50)→160(10)→184(24)→90(94)→58(32)→55(3)→39(16)→38(1)→18(20)
总距离 = 50+10+24+94+32+3+16+1+20 = 250（同SCAN）
```

#### C-LOOK

```
向外扫到184，跳到18，继续向外：
100→150(50)→160(10)→184(24)→18(166)→38(20)→39(1)→55(16)→58(3)→90(32)
总距离 = 50+10+24+166+20+1+16+3+32 = 322
```

## 五、磁盘容量计算

### 5.1 计算公式

```
非格式化容量 = 扇区数 × 每扇区字节数 × 磁道数 × 盘面数 × 盘片数
格式化容量 = 可用扇区数 × 每扇区字节数 × 磁道数 × 盘面数 × 盘片数

数据传输率 = 转速(rpm) × 每磁道扇区数 × 每扇区字节数 / 60

平均等待时间 = 60 / (2 × 转速) 秒
```

### 5.2 典型题目

**题目**：磁盘组有6片盘片，每片2个记录面，每面256个磁道，每磁道16个扇区，每扇区512字节，转速7200rpm。

**解答**：
```
记录面数 = 6 × 2 = 12（最外和最内的面不记录）
实际记录面 = (6-1) × 2 = 10

非格式化容量 = 16 × 512 × 256 × 10 = 20,971,520 字节 = 20MB

数据传输率 = 7200 × 16 × 512 / 60 = 983,040 字节/秒 ≈ 960KB/s

平均等待时间 = 60 / (2 × 7200) = 4.17ms
```

1. 周转时间 = 完成时间 - 到达时间
