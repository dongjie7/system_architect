## 一、文件系统基本概念

### 1.1 文件的概念

**文件**：一组相关信息的集合，有名字，存储在外部存储器上。

**文件系统**：OS中负责管理和存取文件的软件机构。

### 1.2 文件的逻辑结构

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| **流式文件** | 无结构的字符流 | 源程序、文本文件 |
| **记录式文件** | 有结构的记录序列 | 数据库、表格 |

### 1.3 文件的物理结构（存储方式）

| 方式 | 思想 | 优点 | 缺点 |
|------|------|------|------|
| **连续分配** | 文件占用连续的磁盘块 | 顺序访问快 | 外部碎片、文件扩展难 |
| **链接分配** | 每块存下一块指针 | 无碎片、易扩展 | 只能顺序访问 |
| **索引分配** | 索引块存所有块号 | 支持随机访问 | 索引块占用空间 |

```c
// 连续分配
struct ContiguousFile {
    int start_block;    // 起始块号
    int length;         // 文件长度（块数）
};

// 链接分配（隐式）
struct LinkedBlock {
    char data[BLOCK_SIZE - 4];  // 数据
    int next_block;             // 下一块指针
};

// 索引分配
struct IndexBlock {
    int blocks[MAX_BLOCKS];     // 块号数组
};
```

## 二、文件目录

### 2.1 目录结构

| 结构 | 特点 | 适用 |
|------|------|------|
| **一级目录** | 所有文件在同一目录 | 单用户 |
| **二级目录** | 每个用户一个目录 | 多用户隔离 |
| **树形目录** | 层次结构 | 现代OS |
| **有向无环图** | 允许共享 | 高级需求 |

### 2.2 文件控制块（FCB）

```c
// 文件控制块（FCB）/ 索引节点（i-node）
struct FileControlBlock {
    // 基本信息

    int file_id;            // 文件标识
    int file_type;          // 文件类型
    int file_size;          // 文件大小
    
    // 物理信息

    int num_blocks;         // 块数
    
    // 访问控制
    int owner;              // 文件所有者
    int permissions;        // 访问权限（rwx）
    
    // 时间信息
    time_t create_time;     // 创建时间
    time_t modify_time;     // 修改时间
    time_t access_time;     // 访问时间
```

### 2.3 目录项

```c
// 目录项
struct DirectoryEntry {
    char name[256];         // 文件名
    int inode_number;       // i-node编号
};

// 目录查找
int lookup(const char *path) {
    // 解析路径
    char *components[MAX_DEPTH];
    int depth = parse_path(path, components);
    
    // 从根目录开始查找
    int current_inode = ROOT_INODE;
    
    for (int i = 0; i < depth; i++) {
        // 在当前目录中查找
        DirectoryEntry *entries = read_directory(current_inode);
        bool found = false;
        
        for (int j = 0; j < num_entries; j++) {
            if (strcmp(entries[j].name, components[i]) == 0) {
                current_inode = entries[j].inode_number;
                found = true;
                break;
            }
        }
        
        if (!found) return -1;  // 文件不存在
    }
    
    return current_inode;
}
```

## 三、文件存储空间管理

### 3.1 空闲空间管理方法

| 方法 | 思想 | 适用场景 |
|------|------|----------|
| **空闲表法** | 记录连续空闲块的起始和长度 | 空闲块连续时 |
| **空闲链表法** | 空闲块/空闲盘区链接成链 | 文件系统 |
| **位示图法** | 每位表示一块的状态 | 最常用 |
| **成组链接法** | Unix/Linux使用 | 大型文件系统 |

### 3.2 位示图法

```c
// 位示图（Bitmap）
// 每个bit表示一个磁盘块：0=空闲，1=已用

#define BLOCKS_PER_WORD 32
unsigned int bitmap[TOTAL_BLOCKS / BLOCKS_PER_WORD + 1];

// 分配一个空闲块
int allocate_block() {
    for (int i = 0; i < TOTAL_BLOCKS / BLOCKS_PER_WORD + 1; i++) {
        if (bitmap[i] != 0xFFFFFFFF) {  // 有空闲位
            for (int j = 0; j < BLOCKS_PER_WORD; j++) {
                if (!(bitmap[i] & (1 << j))) {  // 找到空闲位
                    bitmap[i] |= (1 << j);      // 标记为已用
                    return i * BLOCKS_PER_WORD + j;
                }
            }
        }
    }
    return -1;  // 无空闲块
}

// 释放一个块
void free_block(int block_num) {
    int word = block_num / BLOCKS_PER_WORD;
    int bit = block_num % BLOCKS_PER_WORD;
    bitmap[word] &= ~(1 << bit);  // 清零
}

// 计算空闲空间
int count_free_blocks() {
    int count = 0;
    for (int i = 0; i < TOTAL_BLOCKS / BLOCKS_PER_WORD + 1; i++) {
        count += __builtin_popcount(~bitmap[i]);
    }
    return count;
}
```

### 3.3 成组链接法（Unix/Linux）

```
超级块记录：
┌────────────────────────────────┐
│ 空闲块组数（如100）             │
│ 空闲块号[0] = 下一组首块号      │
│ 空闲块号[1] = 空闲块号         │
│ ...                            │
│ 空闲块号[99] = 空闲块号        │
└────────────────────────────────┘

分配：
1. 从超级块取空闲块号
2. 若取的是最后一块，将该块内容复制到超级块
3. 返回分配的块号

释放：
1. 若超级块已满，将超级块内容写入该块
2. 将该块号记入超级块
```

## 四、磁盘调度算法（必考）

### 4.1 磁盘访问时间

```
磁盘访问时间 = 寻道时间 + 旋转延迟 + 传输时间

寻道时间：磁头移动到目标磁道（最耗时）
旋转延迟：等待目标扇区转到磁头下
传输时间：读写数据

优化重点：减少寻道时间（磁头移动距离）
```

### 4.2 磁盘调度算法对比

| 算法 | 思想 | 优点 | 缺点 |
|------|------|------|------|
| **FCFS** | 按请求顺序 | 公平 | 寻道距离长 |
| **SSTF** | 最短寻道优先 | 减少寻道 | 可能饥饿 |
| **SCAN** | 电梯算法，单方向扫到底 | 公平、无饥饿 | 两端等待长 |
| **C-SCAN** | 循环扫描，返回时不服务 | 等待均匀 | 返回时不服务 |
| **LOOK** | 单方向扫到最远请求 | 比SCAN好 | - |
| **C-LOOK** | 循环扫描到最远请求 | 等待最均匀 | - |

### 4.3 磁盘调度计算实例

**题目**：磁头当前位置在100号磁道，刚完成98号磁道的服务，正在向磁道号增大的方向移动。
请求队列：55, 58, 39, 18, 90, 160, 150, 38, 184

#### FCFS（先来先服务）

```
服务顺序: 55, 58, 39, 18, 90, 160, 150, 38, 184
移动距离: |100-55| + |55-58| + |58-39| + |39-18| + |18-90| + |90-160| + |160-150| + |150-38| + |38-184|
        = 45 + 3 + 19 + 21 + 72 + 70 + 10 + 112 + 146
        = 498
```

#### SSTF（最短寻道优先）

```
当前位置: 100
选择最近: 90 (距离10)
然后: 58, 55, 39, 38, 18 (距离依次)
然后: 150, 160, 184

服务顺序: 90, 58, 55, 39, 38, 18, 150, 160, 184
移动距离: |100-90| + |90-58| + |58-55| + |55-39| + |39-38| + |38-18| + |18-150| + |150-160| + |160-184|
        = 10 + 32 + 3 + 16 + 1 + 20 + 132 + 10 + 24
        = 248
```

#### SCAN（电梯算法）

```
方向: 向外（磁道号增大方向）
先向外扫到最远请求: 184
再向内扫到最远请求: 18

服务顺序: 150, 160, 184, 90, 58, 55, 39, 38, 18
移动距离: |100-150| + |150-160| + |160-184| + |184-90| + |90-58| + |58-55| + |55-39| + |39-38| + |38-18|
        = 50 + 10 + 24 + 94 + 32 + 3 + 16 + 1 + 20
        = 250
```

#### C-SCAN（循环扫描）

```
方向: 向外
先向外扫到184，然后直接回到起点，再向外扫

服务顺序: 150, 160, 184, (回到0), 18, 38, 39, 55, 58, 90
移动距离: |100-150| + |150-160| + |160-184| + |184-0| + |0-18| + |18-38| + |38-39| + |39-55| + |55-58| + |58-90|
        = 50 + 10 + 24 + 184 + 18 + 20 + 1 + 16 + 3 + 32
        = 358
```

#### LOOK

```
方向: 向外
扫到最远请求184就反向，不到边界

服务顺序: 150, 160, 184, 90, 58, 55, 39, 38, 18
移动距离: 同SCAN = 250（本例中184是最外请求）
```

#### C-LOOK

```
方向: 向外
扫到184后直接跳到18继续

服务顺序: 150, 160, 184, (跳到18), 38, 39, 55, 58, 90
移动距离: |100-150| + |150-160| + |160-184| + |184-18| + |18-38| + |38-39| + |39-55| + |55-58| + |58-90|
        = 50 + 10 + 24 + 166 + 20 + 1 + 16 + 3 + 32
        = 322
```

### 4.4 磁盘调度算法代码实现

```c
// FCFS 磁盘调度
int fcfs_disk(int queue[], int n, int head) {
    int total_movement = 0;
    int current = head;
    
    printf("服务顺序: ");
    for (int i = 0; i < n; i++) {
        total_movement += abs(current - queue[i]);
        current = queue[i];
        printf("%d ", queue[i]);
    }
    printf("\n");
    
    return total_movement;
}

// SSTF 磁盘调度
int sstf_disk(int queue[], int n, int head) {
    bool visited[n];
    int total_movement = 0;
    int current = head;
    
    for (int i = 0; i < n; i++) visited[i] = false;
    
    printf("服务顺序: ");
    for (int count = 0; count < n; count++) {
        int min_dist = MAX_INT;
        int min_idx = -1;
        
        // 找最近的请求
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                int dist = abs(current - queue[i]);
                if (dist < min_dist) {
                    min_dist = dist;
                    min_idx = i;
                }
            }
        }
        
        visited[min_idx] = true;
        total_movement += min_dist;
        current = queue[min_idx];
        printf("%d ", current);
    }
    printf("\n");
    
    return total_movement;
}

// SCAN 磁盘调度（电梯算法）
int scan_disk(int queue[], int n, int head, int direction, int max_track) {
    // 排序请求队列
    int sorted[n];
    memcpy(sorted, queue, n * sizeof(int));
    quick_sort(sorted, n);
    
    int total_movement = 0;
    int current = head;
    
    printf("服务顺序: ");
    
    if (direction == 1) {  // 向外
        // 先向外服务
        for (int i = 0; i < n; i++) {
            if (sorted[i] >= head) {
                total_movement += abs(current - sorted[i]);
                current = sorted[i];
                printf("%d ", current);
            }
        }
        // 到达边界
        total_movement += abs(current - max_track);
        current = max_track;
        
        // 反向向内
        for (int i = n - 1; i >= 0; i--) {
            if (sorted[i] < head) {
                total_movement += abs(current - sorted[i]);
                current = sorted[i];
                printf("%d ", current);
            }
        }
    } else {  // 向内
        // 先向内服务
        for (int i = n - 1; i >= 0; i--) {
            if (sorted[i] <= head) {
                total_movement += abs(current - sorted[i]);
                current = sorted[i];
                printf("%d ", current);
            }
        }
        // 到达边界
        total_movement += current;
        current = 0;
        
        // 反向向外
        for (int i = 0; i < n; i++) {
            if (sorted[i] > head) {
                total_movement += abs(current - sorted[i]);
                current = sorted[i];
                printf("%d ", current);
            }
        }
    }
    printf("\n");
    
    return total_movement;
}

// C-SCAN 磁盘调度
int cscan_disk(int queue[], int n, int head, int max_track) {
    int sorted[n];
    memcpy(sorted, queue, n * sizeof(int));
    quick_sort(sorted, n);
    
    int total_movement = 0;
    int current = head;
    
    printf("服务顺序: ");
    
    // 向外服务
    for (int i = 0; i < n; i++) {
        if (sorted[i] >= head) {
            total_movement += abs(current - sorted[i]);
            current = sorted[i];
            printf("%d ", current);
        }
    }
    
    // 回到起点
    total_movement += abs(current - max_track);
    total_movement += max_track;
    current = 0;
    
    // 继续向外服务
    for (int i = 0; i < n; i++) {
        if (sorted[i] < head) {
            total_movement += abs(current - sorted[i]);
            current = sorted[i];
            printf("%d ", current);
        }
    }
    printf("\n");
    
    return total_movement;
}
```

## 五、文件存取控制

### 5.1 文件权限

```
Unix/Linux 权限模型：
rwx rwx rwx
│   │   │
│   │   └── 其他用户权限
│   └────── 同组用户权限
└────────── 文件所有者权限

r = 读(4), w = 写(2), x = 执行(1)

示例：
-rw-r--r--  文件所有者可读写，其他人只读
-rwxr-xr-x  所有者可执行，其他人可读可执行
```

### 5.2 访问控制矩阵

```
        文件A   文件B   文件C
用户1   rwx     r--     rw-
用户2   r-x     rw-     ---
用户3   ---     rwx     r--

实现方式：
1. 访问控制矩阵（直接）
2. 访问控制表（ACL）
3. 用户权限表
```
