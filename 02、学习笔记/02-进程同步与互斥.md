## 一、基本概念

### 1.1 临界资源与临界区

**临界资源（Critical Resource）**：一次仅允许一个进程使用的资源
- 如：打印机、共享变量、共享缓冲区

**临界区（Critical Section）**：访问临界资源的代码段

```c
// 进程访问临界区的通用结构
do {
    // 进入区（Entry Section）：请求进入临界区
    entry_section();
    
    // 临界区（Critical Section）：访问临界资源
    critical_section();
    
    // 退出区（Exit Section）：释放临界区
    exit_section();
    
    // 剩余区（Remainder Section）：其他代码
    remainder_section();
} while (true);
```

### 1.2 同步与互斥

| 概念 | 含义 | 举例 |
|------|------|------|
| **互斥** | 对临界资源的排他性访问 | 两个进程不能同时进入同一临界区 |
| **同步** | 进程间的执行顺序约束 | 生产者必须先生产，消费者才能消费 |

### 1.3 临界区访问准则

1. **互斥访问**：同一时刻最多一个进程在临界区
2. **空闲让进**：临界区空闲时，申请进程应立即进入
3. **有限等待**：进程请求进入临界区时，应在有限时间内获准
4. **让权等待**（可选）：不能进入临界区的进程应释放CPU

## 二、信号量机制（PV操作）

### 2.1 信号量的定义

```c
// 信号量结构
typedef struct {
    int value;           // 资源计数
    Queue L;             // 等待队列
} Semaphore;

// P操作（wait / down / 申请）
void P(Semaphore S) {
    S.value--;
    if (S.value < 0) {
        // 资源不足，进程阻塞，加入等待队列
        block(S.L);
    }
}

// V操作（signal / up / 释放）
void V(Semaphore S) {
    S.value++;
    if (S.value <= 0) {
        // 有进程在等待，唤醒一个
        wakeup(S.L);
    }
}
```

### 2.2 信号量的含义

| 信号量值 | 含义 |
|----------|------|
| S.value > 0 | 可用资源数量 |
| S.value = 0 | 资源刚好用完，无等待进程 |
| S.value < 0 | |S.value| 为等待队列中的进程数 |

### 2.3 信号量分类

| 类型 | 取值范围 | 用途 |
|------|----------|------|
| **整型信号量** | 任意整数 | 互斥、同步 |
| **记录型信号量** | 任意整数（含等待队列） | 互斥、同步（推荐） |
| **二值信号量（互斥锁）** | 0或1 | 仅用于互斥 |

### 2.4 PV操作实现互斥

```c
// 互斥信号量
Semaphore mutex = 1;  // 初始值为1

// 进程Pi
void process_i() {
    while (true) {
        P(mutex);       // 进入临界区
        // 访问临界资源
        V(mutex);       // 退出临界区
        // 剩余区
    }
}

// 进程Pj
void process_j() {
    while (true) {
        P(mutex);       // 进入临界区
        // 访问临界资源
        V(mutex);       // 退出临界区
        // 剩余区
    }
}
```

**互斥实现要点：**
- 信号量初值 = 1（表示资源可用）
- P(mutex) 和 V(mutex) 必须成对出现
- 同一进程对同一信号量的PV操作不能颠倒

### 2.5 PV操作实现同步

```c
// 同步信号量
Semaphore empty = N;   // 空缓冲区数量，初值为N
Semaphore full = 0;    // 满缓冲区数量，初值为0

// 生产者进程
void producer() {
    while (true) {
        produce_item();     // 生产产品
        P(empty);           // 等待空位
        P(mutex);           // 进入临界区
        put_item();         // 放入产品
        V(mutex);           // 退出临界区
        V(full);            // 增加满位数
    }
}

// 消费者进程
void consumer() {
    while (true) {
        P(full);            // 等待产品
        P(mutex);           // 进入临界区
        take_item();        // 取走产品
        V(mutex);           // 退出临界区
        V(empty);           // 增加空位数
        consume_item();     // 消费产品
    }
}
```

**同步实现要点：**
- 先P同步信号量，再P互斥信号量（**顺序不能反！**）
- 先V互斥信号量，再V同步信号量

## 三、经典同步问题（考试重点）

### 3.1 生产者-消费者问题

**问题描述：**
- 有界缓冲区（大小为N）
- 生产者生产产品放入缓冲区
- 消费者从缓冲区取出产品消费
- 缓冲区满时生产者等待，缓冲区空时消费者等待

**完整解决方案：**

```c
// 信号量定义
Semaphore mutex = 1;      // 互斥访问缓冲区
Semaphore empty = N;      // 空缓冲区数量
Semaphore full = 0;       // 满缓冲区数量
int buffer[N];            // 缓冲区
int in = 0, out = 0;      // 生产者/消费者指针

// 生产者
void producer() {
    while (true) {
        int item = produce();     // 生产
        P(empty);                 // 等待空位
        P(mutex);                 // 进入临界区
        
        buffer[in] = item;        // 放入产品
        in = (in + 1) % N;        // 循环使用
        
        V(mutex);                 // 退出临界区
        V(full);                  // 通知消费者
    }
}

// 消费者
void consumer() {
    while (true) {
        P(full);                  // 等待产品
        P(mutex);                 // 进入临界区
        
        int item = buffer[out];   // 取走产品
        out = (out + 1) % N;      // 循环使用
        
        V(mutex);                 // 退出临界区
        V(empty);                 // 通知生产者
        
        consume(item);            // 消费
    }
}
```

**易错点：**
- P操作顺序：先P(empty/full)，再P(mutex)
- V操作顺序：先V(mutex)，再V(full/empty)
- mutex只能有一个P和一个V，不能连续P两次

### 3.2 读者-写者问题

**问题描述：**
- 共享数据对象
- 读者只读，写者读写
- 多个读者可同时读
- 写者写时不能有其他读者或写者

#### 读者优先（可能导致写者饥饿）

```c
Semaphore mutex = 1;      // 保护read_count
Semaphore w_mutex = 1;    // 写者互斥
int read_count = 0;       // 读者计数

// 读者
void reader() {
    while (true) {
        P(mutex);
        if (read_count == 0) {
            P(w_mutex);   // 第一个读者阻塞写者
        }
        read_count++;
        V(mutex);
        
        // 读数据
        read_data();
        
        P(mutex);
        read_count--;
        if (read_count == 0) {
            V(w_mutex);   // 最后一个读者释放写者
        }
        V(mutex);
    }
}

// 写者
void writer() {
    while (true) {
        P(w_mutex);       // 等待无读者
        // 写数据
        write_data();
        V(w_mutex);
    }
}
```

#### 写者优先（可能导致读者饥饿）

```c
Semaphore mutex = 1;      // 保护read_count
Semaphore w_mutex = 1;    // 写者互斥
Semaphore r_mutex = 1;    // 读者排队
int read_count = 0;

// 读者
void reader() {
    while (true) {
        P(r_mutex);       // 等待写者优先权
        P(mutex);
        if (read_count == 0) {
            P(w_mutex);
        }
        read_count++;
        V(mutex);
        V(r_mutex);
        
        read_data();
        
        P(mutex);
        read_count--;
        if (read_count == 0) {
            V(w_mutex);
        }
        V(mutex);
    }
}

// 写者
void writer() {
    while (true) {
        P(r_mutex);       // 获取优先权
        P(w_mutex);
        write_data();
        V(w_mutex);
        V(r_mutex);
    }
}
```

### 3.3 哲学家进餐问题

**问题描述：**
- 5个哲学家围坐圆桌
- 每人左右各一根筷子（共5根）
- 思考→饥饿→进餐
- 进餐需要同时拿起左右两根筷子

#### 解决方案一：限制最多4人同时拿筷子

```c
Semaphore chopstick[5] = {1, 1, 1, 1, 1};
Semaphore room = 4;       // 最多4人同时

void philosopher(int i) {
    while (true) {
        think();
        P(room);          // 进入餐厅
        P(chopstick[i]);              // 拿左筷子
        P(chopstick[(i+1) % 5]);      // 拿右筷子
        eat();
        V(chopstick[(i+1) % 5]);      // 放右筷子
        V(chopstick[i]);              // 放左筷子
        V(room);          // 离开餐厅
    }
}
```

#### 解决方案二：奇数先左后右，偶数先右后左

```c
void philosopher(int i) {
    while (true) {
        think();
        if (i % 2 == 1) {
            P(chopstick[i]);
            P(chopstick[(i+1) % 5]);
        } else {
            P(chopstick[(i+1) % 5]);
            P(chopstick[i]);
        }
        eat();
        V(chopstick[(i+1) % 5]);
        V(chopstick[i]);
    }
}
```

#### 解决方案三：AND信号量（同时申请两根筷子）

```c
void philosopher(int i) {
    while (true) {
        think();
        // Swait: 同时申请两个资源，避免死锁
        Swait(chopstick[i], chopstick[(i+1) % 5]);
        eat();
        Ssignal(chopstick[i], chopstick[(i+1) % 5]);
    }
}
```

### 3.4 吸烟者问题

**问题描述：**
- 3个吸烟者 + 1个供应商
- 吸烟者A有烟草，B有纸，C有火柴
- 供应商随机提供两种材料，只有对应吸烟者能吸烟

```c
Semaphore offer = 0;          // 供应商提供材料
Semaphore tobacco = 0;        // 烟草
Semaphore paper = 0;          // 纸
Semaphore match = 0;          // 火柴

// 供应商
void provider() {
    while (true) {
        int random = rand() % 3;
        if (random == 0) V(tobacco);   // 提供烟草（B可吸烟）
        else if (random == 1) V(paper); // 提供纸（C可吸烟）
        else V(match);                  // 提供火柴（A可吸烟）
        V(offer);
    }
}

// 吸烟者A（有烟草，需要纸和火柴）
void smoker_A() {
    while (true) {
        P(offer);
        P(paper);
        P(match);
        smoke();
    }
}

// 吸烟者B（有纸，需要烟草和火柴）
void smoker_B() {
    while (true) {
        P(offer);
        P(tobacco);
        P(match);
        smoke();
    }
}

// 吸烟者C（有火柴，需要烟草和纸）
void smoker_C() {
    while (true) {
        P(offer);
        P(tobacco);
        P(paper);
        smoke();
    }
}
```

## 四、管程（Monitor）

### 4.1 管程的概念

**管程**是一种高级同步机制，封装共享资源和操作过程。

```
管程 = 局部变量 + 操作过程（过程/函数） + 条件变量

特点:
1. 模块化封装共享资源
2. 自动互斥（同一时刻只有一个进程在管程中）
3. 通过条件变量实现同步
```

### 4.2 条件变量

```c
// 条件变量操作
wait(condition_var);     // 等待条件成立，释放管程
signal(condition_var);   // 通知等待进程条件可能成立

// 管程示例
monitor ProducerConsumer {
    int buffer[N];
    int count = 0;
    condition not_full, not_empty;
    
    void produce(int item) {
        if (count == N) wait(not_full);
        buffer[count++] = item;
        signal(not_empty);
    }
    
    int consume() {
        if (count == 0) wait(not_empty);
        int item = buffer[--count];
        signal(not_full);
        return item;
    }
}
```

## 五、本章高频考点速记

### 必背知识点

1. 临界区访问准则：互斥、空闲让进、有限等待、让权等待
2. PV操作的语义：P申请（-1），V释放（+1）
3. 互斥信号量初值为1，同步信号量初值为0或资源数
4. PV操作顺序：先同步后互斥（P操作），先互斥后同步（V操作）
5. 生产者-消费者、读者-写者、哲学家进餐问题的解决方案
6. 管程是高级同步机制，自动保证互斥

### 典型真题

**【选择题】用PV操作实现进程互斥时，信号量的初值应设置为（ ）**
A. 0  B. 1  C. -1  D. 资源数

**答案：B**（互斥信号量初值为1）

**【选择题】在生产者-消费者问题中，P操作的顺序是（ ）**
A. 先P(mutex)后P(empty)  B. 先P(empty)后P(mutex)
C. 顺序无所谓            D. 只能P(empty)

**答案：B**（先P同步信号量，后P互斥信号量）
